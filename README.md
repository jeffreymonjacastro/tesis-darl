## DARL

Repositorio monorepo para la tesis DARL: Drift-Aware Reinforcement Learning for
selective updating of two-stage tabular ML pipelines.

Este repositorio separa la tesis escrita en LaTeX, el código experimental en
Python, los datos locales, los resultados generados y la literatura de apoyo.

## Estructura

- `.agents/`: documentación de futuras skills de Codex para este repositorio.
- `thesis/`: fuente de la tesis, figuras, tablas, estilos y build local.
- `code/`: paquete Python, experimentos, notebooks y pruebas.
- `data/`: datos locales, ignorados por Git salvo los `README.md`.
- `outputs/`: modelos, métricas, logs, figuras y tablas generadas, ignorados por
  Git salvo los `README.md`.
- `literature/`: papers, notas y referencias BibTeX.
- `scripts/`: scripts auxiliares futuros.

Los archivos de implementación, datasets, modelos y resultados se agregarán en
tareas posteriores.
