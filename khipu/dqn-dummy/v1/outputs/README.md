# Resultados de DDQN Khipu v1

Los subdirectorios `pilot/` y `full/` contienen resultados generados y están
excluidos de Git. Consultar `../README.md` para esquema, reproducción y
reanudación. No usar el piloto como evidencia de los 1000 episodios FULL.

test terminado e integridad aprobada acredita completitud experimental.
La cualificación de calibración y el desempeño se reportan por separado.
