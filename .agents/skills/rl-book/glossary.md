# Glossary

- **Agent:** learner or controller that selects actions.
- **Environment:** system with which the agent interacts.
- **State:** representation of the current situation.
- **Observation:** information available to the agent when the true state may be hidden.
- **Action:** choice made by the agent.
- **Reward:** scalar feedback signal.
- **Return:** discounted sum of future rewards.
- **Policy:** mapping from states or observations to actions.
- **Value function:** expected return from a state or state-action pair.
- **Bellman equation:** recursive relationship between current value, reward, and future value.
- **MDP:** fully observed sequential decision process.
- **POMDP:** sequential decision process with hidden state and partial observations.
- **Monte Carlo learning:** learning from sampled complete returns.
- **Temporal-difference learning:** learning from bootstrapped reward-plus-next-value targets.
- **Function approximation:** using parameterized models to generalize value or policy estimates.
- **Policy gradient:** direct optimization of a parameterized policy.
- **Actor-critic:** architecture with policy actor and value critic.
- **Advantage:** how much better an action is than the state's expected baseline value.
